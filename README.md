# Muhammad Ishaque Portfolio

Personal portfolio website for Muhammad Ishaque, a frontend and full-stack JavaScript developer based in Karachi, Pakistan. The site is a static HTML, CSS, and vanilla JavaScript project with GSAP entrance animations.

## Features

- Responsive portfolio sections for About, Projects, Activity, and Contact.
- Dark technical visual style with Space Grotesk, JetBrains Mono, and Inter typography.
- Accessible image alt text, keyboard focus states, reduced-motion support, and secure external links.
- SEO metadata, canonical URL, Open Graph/Twitter cards, JSON-LD structured data, `robots.txt`, and `sitemap.xml`.

## Project files

- `index.html` contains the page structure, metadata, JSON-LD, project links, and contact links.
- `style.css` contains the layout, responsive rules, colors, and visual styles.
- `script.js` handles the custom cursor and GSAP loading/intro animation.
- `profile.jpg` is the profile image used in the hero and About section.
- `logo.png` is the favicon.
- `robots.txt` allows crawling and references the production sitemap.
- `sitemap.xml` contains the production portfolio URL.
- `llms.txt` provides a concise, machine-readable profile and project summary.

## Run locally

Open `index.html` directly in a browser, or serve the folder with a static server. In VS Code, right-click `index.html` and choose **Open with Live Server**.

The page loads GSAP, Font Awesome, and Google Fonts from external CDNs, so an internet connection is needed for the complete visual experience and entrance animation.
